`S2` currently has built-in text for `Chinese`, `English`, and `Russian` (community-provided), with **Chinese** as the default. [View all files](https://github.com/antvis/S2/tree/next/packages/s2-core/src/common/i18n).

## Switching to English

You can switch the internationalization text using `setLang`. Note: this needs to be called before the spreadsheet is instantiated.

```ts
import { setLang, PivotSheet } from '@antv/s2'

setLang('en_US')
// setLang('zh_CN')
// setLang('ru_RU');

const s2 = new PivotSheet(...)
await s2.render()
```

## Extending Internationalization Text

You can extend the internationalization text using `extendLocale`. Note: this also needs to be called before the spreadsheet is instantiated.

```ts
import { i18n, extendLocale } from '@antv/s2'

const locale = {
  zh_CN: {
    test: 'Test',
  },
  en_US: {
    test: 'test',
  },
  ru_RU: {
    test: 'тест',
  },
};

extendLocale(locale)

// Usage
i18n('test')
```

## Utility Methods

```ts
import { i18n, getLocale, getLang, setLang } from '@antv/s2'

// Get the current language
getLang()  // 'zh_CN'

// Switch language
setLang('en_US')

// Get the current internationalization file
getLocale()

// Internationalization function
i18n('Hide') // 'Hide'
```
